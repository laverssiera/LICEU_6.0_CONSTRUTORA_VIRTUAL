# Estrutura de Diretórios - LICEU 6.0 Runtime

Esta pasta segue o blueprint do LICEU 6.0 para o núcleo do runtime autônomo e federado.

## Subdiretórios

- **agi/**: Núcleo de AGI federada
- **federation/**: Módulos de federação e soberania
- **digital_twin/**: Runtime de Digital Twin global
- **causal/**: Motor causal e grafo causal
- **sovereign/**: Malha de federação soberana
- **observability/**: Observabilidade e monitoramento
- **orchestration/**: Orquestração de fluxos e agentes
- **simulations/**: Camada de simulação global
- **agents/**: Agentes autônomos e inteligentes
- **memory/**: Memória e armazenamento cognitivo

Consulte o arquivo README_MONOLITO_BLUEPRINT.md na raiz para detalhes do blueprint e objetivos de cada módulo.
