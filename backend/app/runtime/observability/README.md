# Observabilidade

Módulo responsável por tracing, métricas e auditoria do runtime LICEU 6.0.

## Principais arquivos
- `tracing.py`: Rastreio de operações
- `metrics.py`: Métricas do sistema
- `audit.py`: Auditoria de ações e decisões

> Integrado ao Kernel e aos demais módulos para garantir rastreabilidade e transparência.
