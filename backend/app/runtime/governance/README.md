# Módulo de Governança

Responsável por avaliar eventos, aplicar políticas, aprovar decisões e calcular riscos no ecossistema LICEU 6.0.

## Principais arquivos
- `governance_engine.py`: Avaliação de eventos e decisões
- `risk_engine.py`: Avaliação de risco
- `approval_engine.py`: Lógica de aprovação humana/monolito

> Este módulo é chamado pelo Kernel durante o ciclo de decisão.
